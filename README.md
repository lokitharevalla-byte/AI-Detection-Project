# 🚗 AI-Based Drowsiness Detection System

## 📌 Project Description
This project detects multiple people in real-time and identifies whether they are sleeping or awake using computer vision.

---

## ⚙️ Features
- Real-time face detection
- Sleep vs awake classification
- Multiple person detection
- Age estimation (demo-based)
- Live webcam support
